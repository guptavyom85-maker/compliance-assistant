# Demonstration guide

## Available now

1. Start Django, sign in and run the index integrity command. Inspect /system/index-status/ as Admin.
2. Inspect Documents: the consultation is draft and the financial report is not binding regulation. Open their authenticated PDFs.
3. Ask a source-supported question in dense, hybrid and reranked modes. Inspect claim citations and support; provider availability is required.
4. Force agent strategy for a comparison question; inspect its saved operational trace. Version-change questions require properly dated sources sharing a version family.
5. Open Evaluation. Show pending references and provisional retrieval runs without approving anything. Explain that retrieval scores do not measure answer accuracy.
6. Open the admin review queue, analytics and trust page. Compare Viewer/Contributor/Admin access.
7. Run the regression suite. Tests mock remote generation and use isolated temporary data.

## Requires additional real sources and human input

1. Upload an authorized in-force binding source and a company policy; accurately classify and index both.
2. Extract obligations in bounded batches. Review every proposed duty/quote, correcting or rejecting as needed.
3. Create a gap analysis for the policy against selected regulations with confirmed obligations.
4. Inspect source evidence for each finding, perform human review and export the PDF.
5. Record at least five genuine reviewed findings before claiming the Phase 2 acceptance condition is met.

The current two supplied PDFs deliberately do not qualify as binding obligation sources. Do not relabel them to bypass this guard. Synthetic tests cover all five statuses but are not real compliance findings.
